# NANINANA — The Everyday Agent

Responsive React + TypeScript + Vite prototype.

## Run on your computer
1. Install Node.js (LTS) if needed: https://nodejs.org/
2. Extract this ZIP.
3. Open the `naninana-app` folder in VS Code.
4. Choose **Terminal → New Terminal**.
5. Run `npm install`.
6. Run `npm run dev`.
7. Open the local URL Vite prints (usually http://localhost:5173).

## Included
- Today dashboard and secret briefing
- Original flat 2D SVG agent mascot
- Everyday recommendations and mission browser
- Search and category filters
- Accept, skip and complete mission actions
- XP, active mission radar and sticky-note achievements
- Responsive mobile navigation
- Progress saved in browser local storage

This is a first prototype. It uses sample missions and local browser storage; accounts, cloud sync, scheduled reminders and notifications are not connected yet.
